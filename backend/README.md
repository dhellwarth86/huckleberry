# Huckleberry AI Backend (Phase 2)

Python service for PDF intake, data analysis, and persistence.

**Status**: bootstrap only. The Phase 2 v0.1 experiment hasn't run yet. See `PHASE_2_HANDOFF.md` at the repo root.

## Setup

```bash
cd backend
uv venv
source .venv/bin/activate          # or: uv pip ...
uv pip install -e ".[dev]"

# From repo root, start Postgres
cd ..
docker compose up -d postgres
psql postgresql://huckleberry:huckleberry@localhost:5432/huckleberry -c "SELECT 1"
# Expected: ?column? \n ---------- \n 1

# Back to backend/, run smoke tests
cd backend
pytest tests/test_seeds_load.py -v
# Expected: 5 pass (all five seed files import cleanly)
```

## Conventions

- All seed files are **read-only at runtime**. Never mutate them from app code. Edits go through git.
- The wrapper schema lives in `../shared/bidset_record.py`, imported via `pyproject.toml`'s `pythonpath`.
- Per-bidset JSONs in `test_fixtures/experiment_outputs/` are gitignored — they're large and reproducible from the experiment.
- Phase 2 backend runs on **localhost only**. No auth. No network exposure. See `CLAUDE.md` "Phases" section, decision #4.
